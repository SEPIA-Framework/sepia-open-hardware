# SEPIA Open Hardware Projects

A collection of open hardware projects or tutorials useful for voice assistants etc..

- [Proto Voice HAT](proto-voice-HAT) - A custom, DIY voice HAT for Raspberry Pi with microphone, 3W amp and RGB LED
- [Mark II](./mycroft-mark2-4-sepia) - Mycroft Mark II (Dev Kit with SJ201 Daughterboard) installer compatible with SEPIA Client
- [device-setups](./device-setups) - Instructions to set up certain hardware components on different devices

## Related Open Hardware Projects

- [micro:bit remote](https://github.com/SEPIA-Framework/sepia-installation-and-setup/tree/master/sepia-microbit-projects) - BLE based remote compatible with SEPIA beacon scanner
